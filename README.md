# Bank Management System using C

A Bank Management System developed in C using Data Structures and File Handling concepts.

## Features

- Employee Login Authentication
- Customer Account Creation
- Deposit and Withdrawal Operations
- Fund Transfer Functionality
- Account Management
- File-Based Data Storage

## Technologies Used

- C Programming
- Data Structures
- File Handling

- bank.c
- create_employee.c
